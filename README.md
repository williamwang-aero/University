# 📚 University Notes

This repository contains notes from university open days, conferences, information sessions, and other academic events that I attend.

## 📁 Structure

```text
University-Notes/
└── Event Name/
    ├── Notes.md
    ├── images/
    └── resources/
```

Or in path format:

```text
University-Notes/Event Name/Notes.md
University-Notes/Event Name/images/
University-Notes/Event Name/resources/
```

## 🎯 Purpose

* Keep all my university notes in one place.
* Record what I learn at each event.
* Track my journey towards studying aerospace/astronautical engineering.
* Compare different universities and opportunities.
